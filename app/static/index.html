체험용입니다. 휴대폰 사진은 이미 자동 화이트밸런스가 되어 있어, 평가 숫자(정답률)와는 관계가 없어요. 사진 대부분이 한 가지 색이면 보정이 틀릴 수 있어요. 올린 사진은 서버 메모리에만 잠깐 있고 저장되지 않아요.

흰 종이를 네모 안에 꽉 차게 비추고 누르면, 그 종이로 조명 색과 밝기를 맞춰요

흰 종이 기준은 평가하지 않은 기능이에요. 평가 숫자(85.1%)는 자동 보정(Shades of Gray) 기준이에요. 종이와 물건이 같은 빛을 받아야 해요.

폰에서 IP Webcam을 열고 맨 아래 서버 시작을 누른 뒤, 폰 화면 아래에 나오는 주소를 넣으세요. PC와 폰이 같은 와이파이여야 해요. 보정 효과를 보려면 IP Webcam(폰)의 ⋮ → 영상 관련 → 화이트 밸런스를 '자동'이 아닌 값(예: 주광)으로 고정하세요 — 자동이면 폰이 이미 보정해서 보정 전 · 후가 거의 같아요. 화면을 누르면 그곳을 계속 봐요(처음엔 가운데). 체험용이라 평가 숫자와는 관계없어요.
